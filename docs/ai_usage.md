# AI 使用说明

## 游客策略

- 接口按任务书使用 DeepSeek 的 OpenAI 兼容调用，模型参数名为 `deepseek-flash`，思考模式关闭，要求 JSON 输出。
- 2026-09-30 用本机 `.env` 里的密钥运行 `build_policies.py`，六组全部成功，`source=llm`，模型名是接口返回的 `deepseek-flash`。策略指纹 `c6ea1f159a372cb9`。文件里有生成时间、摘要和 token 用量，没有密钥。
- 若某一组调用失败，会重试一次；仍失败就保留备用规则和失败原因，并标 `source=rule_fallback`，不会把备用规则改标成模型生成。
- 仿真、回放、对比和实验都不调用接口。

## 编程协助

仿真、网页和检查代码在 Cursor 里由 AI 编程助手按任务书实现，再由程序自检和页面操作核对。

提交材料里的「AI 辅助代码比例」不要填一个没有数过的百分数。建议队长用下面的方法估计：看最终代码里哪些文件相对任务书示例是新写的、哪些是队长或队友手改过的，用改动行数粗算，并在文档里写明算法是「手改行数 / 总行数」，而不是精确统计。

密钥、账单和私人聊天不进入代码、截图和录像。
